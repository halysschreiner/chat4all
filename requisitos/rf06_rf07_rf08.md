# RF06, RF07, RF08 - Status, Connectors e Notificações em Tempo Real

---

## 1. Resumo dos Requisitos

### RF06 - Controle de Status da Mensagem

> - Implementar transições automáticas de status:
>   - `SENT` → Mensagem criada e publicada no Kafka (✓ cinza).
>   - `DELIVERED` → Processada pelo worker, entregue ao destinatário (✓✓ cinza).
>   - `READ` → Lida pelo destinatário ao abrir a conversa (✓✓ azul).
>   - `FAILED` → Erro no processamento.
> - Atualizar status no banco e notificar via WebSocket ou callback HTTP.
> - Endpoint `POST /v1/conversations/{id}/read` para marcar mensagens como lidas.
> - Endpoint `GET /v1/conversations/{id}/unread` para obter contagem de mensagens não lidas.

### RF07 - Connectors Mock

> - Criar serviços `connector_whatsapp_mock` e `connector_instagram_mock`.
> - Cada connector deve:
>   - Receber mensagens de um tópico Kafka específico (`whatsapp.messages`, `instagram.messages`).
>   - Simular envio com logs (ex: `[WhatsApp] Entregue a usuário X`).
>   - Retornar callback simulando entrega/leitura.

### RF08 - Notificações em Tempo Real

> - Implementar WebSocket Worker para notificações em tempo real.
> - Conexão WebSocket na porta 8082.
> - Autenticação via token JWT na mensagem inicial.
> - Broadcast de atualizações de status para clientes conectados.

### Importância Conjunta

Estes três requisitos formam o **sistema de feedback de entrega** do Chat4All:

```
[RF06: Status] ←→ [RF07: Connectors] ←→ [RF08: WebSocket]
      ↑                   ↑                    ↑
   Máquina de          Simuladores         Notificação
    Estados            de Plataforma        em Tempo Real
```

**Conceito teórico**: Implementam o padrão **State Machine** (SENT → DELIVERED → READ) combinado com **Event-Driven Architecture** via Kafka e WebSocket para propagação de eventos.

### 2.3 Fluxo Completo de Entrega

1. **Envio** (RF03): `POST /v1/messages` → Kafka `messages` → Status `SENT`
2. **Roteamento** (RF07): Router Worker consome → publica em `whatsapp.messages`
3. **Processamento** (RF07): WhatsApp Connector consome → simula envio
4. **Callback** (RF06): Connector envia `POST /v1/callbacks/whatsapp` com status `DELIVERED`
5. **Persistência** (RF06): API atualiza `messages.status` no PostgreSQL
6. **Notificação** (RF08): Redis Pub/Sub → WebSocket Worker → push para cliente
7. **Leitura** (RF06): Destinatário abre conversa → `POST /v1/conversations/{id}/read` → Status `READ`

**Query de atualização (`Database.php`)**:
```php
public function markMessagesAsDelivered(string $conversationId, string $userId): int
{
    $stmt = $this->pdo->prepare('
        UPDATE messages 
        SET status = :new_status, 
            delivered_at = NOW(),
            updated_at = NOW()
        WHERE conversation_id = :conversation_id 
        AND from_user_id != :user_id 
        AND status = :current_status
    ');
    
    $stmt->execute([
        'new_status' => 'DELIVERED',
        'conversation_id' => $conversationId,
        'user_id' => $userId,
        'current_status' => 'SENT'
    ]);
    
    return $stmt->rowCount();
}
```

**Lógica**: Quando usuário B busca mensagens, todas as mensagens de A (status=SENT) são marcadas como DELIVERED.

#### 4.2.2 Message Processor (`MessageProcessor.php`)

**Linhas 60-130**:
```php
public function process(string $payload): void
{
    $data = json_decode($payload, true);
    
    $messageId = $data['message_id'] ?? null;
    $to = $data['to'] ?? 'unknown';
    $text = $data['text'] ?? '';
    $fileId = $data['file_id'] ?? null;

    // Log de recebimento
    $this->logger->info('[WhatsApp] 📥 Mensagem recebida do Kafka', [
        'message_id' => $messageId,
        'to' => $to,
        'has_file' => $fileId !== null
    ]);

    // Simular falha aleatória se configurado
    if ($this->shouldSimulateFailure()) {
        $this->handleFailure($messageId, $to);
        return;
    }

    // Simular processamento e envio
    $this->simulateSending($messageId, $to, $text, $fileId);

    // Enviar callbacks de status
    $this->sendDeliveryCallbacks($messageId, $to);
}

private function simulateSending(string $messageId, string $to, string $text, ?string $fileId): void
{
    // Simular delay de envio (50-200ms)
    usleep(rand(50000, 200000));

    $this->logger->info("[WhatsApp] ✅ Mensagem enviada para {$to}", [
        'message_id' => $messageId
    ]);

    // Callback SENT imediato
    $this->callbackSender->send($messageId, 'SENT', [
        'recipient' => $to,
        'has_attachment' => $fileId !== null
    ]);
}

private function sendDeliveryCallbacks(string $messageId, string $to): void
{
    // DELIVERED após 1-3 segundos
    $this->callbackSender->sendDeliveredWithDelay(
        $messageId,
        $this->deliveryMinDelay,  // 1s
        $this->deliveryMaxDelay   // 3s
    );

    $this->logger->info("[WhatsApp] 📬 Callback DELIVERED enviado", [
        'message_id' => $messageId
    ]);

    // READ após 3-8 segundos
    $this->callbackSender->sendReadWithDelay(
        $messageId,
        $this->readMinDelay,  // 3s
        $this->readMaxDelay   // 8s
    );

    $this->logger->info("[WhatsApp] 👁️ Callback READ enviado", [
        'message_id' => $messageId
    ]);
}
```

```php
class CallbackSender
{
    private string $backendUrl;
    
    public function send(string $messageId, string $status, array $metadata = []): void
    {
        $payload = [
            'message_id' => $messageId,
            'status' => $status,
            'platform' => 'whatsapp',
            'timestamp' => date('c'),
            'metadata' => $metadata
        ];
        
        // POST para o backend
        $this->httpClient->post($this->backendUrl, [
            'json' => $payload
        ]);
    }
    
    public function sendDeliveredWithDelay(string $messageId, int $minDelay, int $maxDelay): void
    {
        sleep(rand($minDelay, $maxDelay));
        $this->send($messageId, 'DELIVERED');
    }
}
```

#### 4.3.2 Status Notification Handler (`StatusNotificationHandler.php`)

**Linhas 25-90** - Estruturas de dados:
```php
class StatusNotificationHandler implements MessageComponentInterface
{
    // Conexões ativas
    protected \SplObjectStorage $connections;

    // user_id => [connectionIds]
    protected array $userConnections = [];

    // connectionId => user_id
    protected array $connectionUsers = [];

    public function onOpen(ConnectionInterface $conn): void
    {
        $this->connections->attach($conn);

        // Solicitar autenticação
        $conn->send(json_encode([
            'type' => 'auth_required',
            'message' => 'Envie seu token JWT para autenticação',
        ]));
    }

    public function onMessage(ConnectionInterface $from, $msg): void
    {
        $data = json_decode($msg, true);

        switch ($data['type']) {
            case 'auth':
                $this->handleAuth($from, $data);
                break;

            case 'ping':
                $from->send(json_encode(['type' => 'pong', 'timestamp' => time()]));
                break;

            case 'subscribe':
                $this->handleSubscribe($from, $data);
                break;
        }
    }
}
```

**Linhas 200-250** - Autenticação JWT:
```php
protected function handleAuth(ConnectionInterface $conn, array $data): void
{
    if (!isset($data['token'])) {
        $conn->send(json_encode([
            'type' => 'auth_error',
            'message' => 'Token não fornecido',
        ]));
        return;
    }

    try {
        // Decodificar JWT
        $decoded = JWT::decode(
            $data['token'],
            new Key($this->config['jwt_secret'], 'HS256')
        );

        $userId = $decoded->sub ?? $decoded->user_id ?? null;

        // Registrar conexão para o usuário
        $resourceId = $conn->resourceId;
        $this->connectionUsers[$resourceId] = $userId;

        if (!isset($this->userConnections[$userId])) {
            $this->userConnections[$userId] = [];
        }
        $this->userConnections[$userId][] = $resourceId;

        $this->logger->info('Usuário autenticado via WebSocket', [
            'userId' => $userId,
            'resourceId' => $resourceId,
        ]);

        $conn->send(json_encode([
            'type' => 'auth_success',
            'user_id' => $userId,
        ]));

    } catch (\Exception $e) {
        $conn->send(json_encode([
            'type' => 'auth_error',
            'message' => $e->getMessage(),
        ]));
    }
}
```

**Broadcast para usuário**:
```php
public function notifyUser(string $userId, array $event): void
{
    if (!isset($this->userConnections[$userId])) {
        return;
    }

    $message = json_encode($event);

    foreach ($this->userConnections[$userId] as $resourceId) {
        foreach ($this->connections as $conn) {
            if ($conn->resourceId === $resourceId) {
                $conn->send($message);
                break;
            }
        }
    }
}
```

### 5.2 Limitações Identificadas

#### Limitação 1: WebSocket Single-Instance

**Problema**: Conexões WebSocket são mantidas em memória local. Múltiplas instâncias não compartilham estado.

**Impacto**: Se usuário conecta na instância A, e evento é gerado na instância B, não recebe notificação.

**Solução**: Usar Redis Pub/Sub como backplane:
```php
// Ao receber evento de status
$redis->publish('ws:events', json_encode($event));

// Cada instância WebSocket escuta o canal
$redis->subscribe(['ws:events'], function($message) {
    $event = json_decode($message, true);
    $this->wsHandler->notifyUser($event['user_id'], $event);
});
```

#### Limitação 2: Callbacks Síncronos nos Connectors

**Problema**: `sleep()` no callback bloqueia a thread:
```php
public function sendDeliveredWithDelay(...): void
{
    sleep(rand($minDelay, $maxDelay)); // BLOQUEANTE!
    $this->send(...);
}
```

**Impacto**: Throughput limitado; um connector processa 1 msg/segundo.

**Solução**: Usar timers assíncronos:
```php
// Com ReactPHP
$loop->addTimer($delay, function() use ($messageId) {
    $this->send($messageId, 'DELIVERED');
});
```

#### Limitação 3: Sem Persistência de Conexões WebSocket

**Problema**: Se WebSocket Worker reinicia, todas as conexões são perdidas.

**Impacto**: Clientes precisam reconectar manualmente.

**Solução**: Client-side auto-reconnect com exponential backoff:
```javascript
function connect() {
    ws = new WebSocket(url);
    ws.onclose = () => {
        setTimeout(connect, Math.min(30000, retryDelay *= 2));
    };
}
```

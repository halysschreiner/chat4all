# RF08 - Notificações em Tempo Real (WebSocket)

---

## 1. Resumo do Requisito

> **RF08**: Implementar WebSocket Worker para notificações em tempo real.
> - Conexão WebSocket na porta 8082.
> - Autenticação via token JWT na mensagem inicial.
> - Broadcast de atualizações de status para clientes conectados.

### Dependências com Outros Requisitos

| Requisito | Tipo de Dependência | Descrição |
|-----------|---------------------|-----------|
| **RF06** | Evento Upstream | Mudanças de status disparam notificações WebSocket |
| **RF07** | Evento Upstream | Callbacks dos connectors geram eventos para broadcast |
| **RF02** | Autenticação | Usa mesmo JWT do sistema de autenticação |
| **RNF01** | Infraestrutura | Define uso de WebSocket para comunicação real-time |

### Conceito Teórico

WebSocket (RFC 6455) fornece comunicação **full-duplex** sobre uma única conexão TCP, eliminando o overhead de polling HTTP. O sistema implementa o padrão **Pub/Sub** onde:

- **Publisher**: API Service (via Redis Pub/Sub)
- **Broker**: Redis channels
- **Subscriber**: WebSocket Worker
- **Consumer**: Clientes conectados via WebSocket

**Trade-off fundamental**:
- **Polling HTTP**: Simples, stateless, mas latência alta (intervalo de poll)
- **WebSocket**: Baixa latência, mas conexão stateful requer gerenciamento

## 3. Stack Tecnológica

| Componente | Tecnologia | Justificativa |
|------------|------------|---------------|
| **WebSocket Server** | Ratchet (PHP) | Biblioteca madura, compatível com PSR-7 |
| **Event Loop** | ReactPHP | Async I/O, permite múltiplas conexões |
| **JWT** | firebase/php-jwt | Padrão de mercado, compatível com API Service |
| **Pub/Sub** | Redis | Baixa latência, suporta múltiplas instâncias |

### Trade-off Considerado

| Alternativa | Prós | Contras | Decisão |
|-------------|------|---------|---------|
| **Socket.io (Node.js)** | Fallback automático, rooms nativas | Stack diferente, overhead de bridge | ❌ Descartado |
| **Ratchet (PHP)** | Mesma stack, simples | Sem fallback WebSocket→polling | ✅ Adotado |
| **Swoole (PHP)** | Alta performance, coroutines | Curva de aprendizado maior | ❌ Descartado |

**Justificativa**: Ratchet mantém consistência de stack e atende requisitos de latência para escala acadêmica.

```php
require __DIR__ . '/vendor/autoload.php';

use Chat4All\WebSocket\StatusNotificationHandler;
use Chat4All\WebSocket\RedisSubscriber;
use React\EventLoop\Loop;
use Ratchet\Server\IoServer;
use Ratchet\Http\HttpServer;
use Ratchet\WebSocket\WsServer;

$config = [
    'websocket_port' => (int)getenv('WEBSOCKET_PORT') ?: 8081,
    'redis_host' => getenv('REDIS_HOST') ?: 'redis',
    'redis_port' => (int)getenv('REDIS_PORT') ?: 6379,
    'jwt_secret' => getenv('JWT_SECRET') ?: 'chat4all_secret_key_2024',
];

$loop = Loop::get();

// Handler de conexões WebSocket
$wsHandler = new StatusNotificationHandler($logger, $config);

// Subscriber Redis para receber eventos
$redisSubscriber = new RedisSubscriber(
    $config['redis_host'],
    $config['redis_port'],
    $wsHandler,
    $logger
);

// Processar mensagens Redis a cada 100ms
$loop->addPeriodicTimer(0.1, function() use ($redisSubscriber) {
    $redisSubscriber->processMessages();
});

// Criar servidor WebSocket
$socket = new \React\Socket\SocketServer('0.0.0.0:' . $config['websocket_port'], [], $loop);
$server = new IoServer(
    new HttpServer(new WsServer($wsHandler)),
    $socket,
    $loop
);

$logger->info("WebSocket server started on port {$config['websocket_port']}");

$loop->run();
```

### 4.3 Status Notification Handler

```php
class StatusNotificationHandler implements MessageComponentInterface
{
    // Conexões ativas
    protected \SplObjectStorage $connections;

    // user_id => [connectionIds]
    protected array $userConnections = [];

    // connectionId => user_id
    protected array $connectionUsers = [];

    public function onOpen(ConnectionInterface $conn): void
    {
        $this->connections->attach($conn);

        $this->logger->info('Nova conexão WebSocket', [
            'resourceId' => $conn->resourceId
        ]);

        // Solicitar autenticação
        $conn->send(json_encode([
            'type' => 'auth_required',
            'message' => 'Envie seu token JWT para autenticação',
        ]));
    }

    public function onMessage(ConnectionInterface $from, $msg): void
    {
        $data = json_decode($msg, true);

        if (!$data || !isset($data['type'])) {
            $from->send(json_encode([
                'type' => 'error',
                'message' => 'Formato de mensagem inválido'
            ]));
            return;
        }

        switch ($data['type']) {
            case 'auth':
                $this->handleAuth($from, $data);
                break;

            case 'ping':
                $from->send(json_encode([
                    'type' => 'pong',
                    'timestamp' => time()
                ]));
                break;

            case 'subscribe':
                $this->handleSubscribe($from, $data);
                break;

            default:
                $from->send(json_encode([
                    'type' => 'error',
                    'message' => 'Tipo de mensagem desconhecido: ' . $data['type']
                ]));
        }
    }

    public function onClose(ConnectionInterface $conn): void
    {
        $resourceId = $conn->resourceId;

        // Remover mapeamentos
        if (isset($this->connectionUsers[$resourceId])) {
            $userId = $this->connectionUsers[$resourceId];
            
            // Remover conexão do array do usuário
            $this->userConnections[$userId] = array_filter(
                $this->userConnections[$userId],
                fn($id) => $id !== $resourceId
            );

            // Limpar array vazio
            if (empty($this->userConnections[$userId])) {
                unset($this->userConnections[$userId]);
            }

            unset($this->connectionUsers[$resourceId]);
        }

        $this->connections->detach($conn);
        
        $this->logger->info('Conexão WebSocket fechada', [
            'resourceId' => $resourceId
        ]);
    }

    public function onError(ConnectionInterface $conn, \Exception $e): void
    {
        $this->logger->error('Erro WebSocket', [
            'resourceId' => $conn->resourceId,
            'error' => $e->getMessage()
        ]);
        
        $conn->close();
    }
}
```

### 4.4 Autenticação JWT

```php
protected function handleAuth(ConnectionInterface $conn, array $data): void
{
    if (!isset($data['token'])) {
        $conn->send(json_encode([
            'type' => 'auth_error',
            'message' => 'Token não fornecido',
        ]));
        return;
    }

    try {
        // Decodificar JWT
        $decoded = JWT::decode(
            $data['token'],
            new Key($this->config['jwt_secret'], 'HS256')
        );

        $userId = $decoded->sub ?? $decoded->user_id ?? null;

        if (!$userId) {
            throw new \Exception('user_id não encontrado no token');
        }

        // Registrar conexão para o usuário
        $resourceId = $conn->resourceId;
        $this->connectionUsers[$resourceId] = $userId;

        if (!isset($this->userConnections[$userId])) {
            $this->userConnections[$userId] = [];
        }
        $this->userConnections[$userId][] = $resourceId;

        $this->logger->info('Usuário autenticado via WebSocket', [
            'userId' => $userId,
            'resourceId' => $resourceId,
            'totalConnections' => count($this->userConnections[$userId])
        ]);

        $conn->send(json_encode([
            'type' => 'auth_success',
            'user_id' => $userId,
        ]));

    } catch (\Firebase\JWT\ExpiredException $e) {
        $conn->send(json_encode([
            'type' => 'auth_error',
            'message' => 'Token expirado',
        ]));
    } catch (\Exception $e) {
        $this->logger->warning('Falha na autenticação WebSocket', [
            'error' => $e->getMessage()
        ]);
        
        $conn->send(json_encode([
            'type' => 'auth_error',
            'message' => 'Token inválido: ' . $e->getMessage(),
        ]));
    }
}
```

### 4.5 Notificação para Usuário

```php
public function notifyUser(string $userId, array $event): void
{
    if (!isset($this->userConnections[$userId])) {
        $this->logger->debug('Usuário não conectado, notificação descartada', [
            'userId' => $userId,
            'event_type' => $event['type'] ?? 'unknown'
        ]);
        return;
    }

    $message = json_encode($event);
    $notified = 0;

    foreach ($this->userConnections[$userId] as $resourceId) {
        foreach ($this->connections as $conn) {
            if ($conn->resourceId === $resourceId) {
                try {
                    $conn->send($message);
                    $notified++;
                } catch (\Exception $e) {
                    $this->logger->error('Erro ao enviar notificação', [
                        'userId' => $userId,
                        'resourceId' => $resourceId,
                        'error' => $e->getMessage()
                    ]);
                }
                break;
            }
        }
    }

    $this->logger->info('Notificação enviada', [
        'userId' => $userId,
        'connections_notified' => $notified,
        'event_type' => $event['type'] ?? 'unknown'
    ]);
}

public function broadcast(array $event): void
{
    $message = json_encode($event);
    
    foreach ($this->connections as $conn) {
        $conn->send($message);
    }
}
```

### 4.6 Redis Subscriber

```php
class RedisSubscriber
{
    private \Redis $redis;
    private StatusNotificationHandler $wsHandler;
    
    public function __construct(
        string $host, 
        int $port, 
        StatusNotificationHandler $handler,
        LoggerInterface $logger
    ) {
        $this->redis = new \Redis();
        $this->redis->connect($host, $port);
        $this->redis->subscribe(['status_updates', 'message_events'], 
            [$this, 'handleMessage']
        );
        $this->wsHandler = $handler;
        $this->logger = $logger;
    }

    public function handleMessage(string $channel, string $message): void
    {
        $data = json_decode($message, true);
        
        if (!$data) {
            $this->logger->warning('Mensagem Redis inválida', [
                'channel' => $channel,
                'message' => $message
            ]);
            return;
        }

        $userId = $data['user_id'] ?? null;
        
        if ($userId) {
            $this->wsHandler->notifyUser($userId, $data);
        } else {
            // Broadcast para todos
            $this->wsHandler->broadcast($data);
        }
    }

    public function processMessages(): void
    {
        // Non-blocking check para novas mensagens
        // ReactPHP event loop processa isso periodicamente
    }
}
```

## 6. Análise Crítica

### 6.1 Conformidade com Requisitos

| Sub-requisito | Status | Evidência |
|---------------|--------|-----------|
| WebSocket Worker | ✅ | `workers/websocket-worker/` |
| Porta 8082 | ⚠️ | Configurado como 8081, **divergência com requisito** |
| Autenticação JWT | ✅ | `handleAuth()` com firebase/php-jwt |
| Broadcast de status | ✅ | `notifyUser()` via Redis Pub/Sub |

### 6.2 Limitações Identificadas

#### Limitação 1: Single-Instance State

**Problema**: Conexões WebSocket são mantidas em memória local do worker.

```php
protected array $userConnections = []; // APENAS NESTA INSTÂNCIA
```

**Impacto**: 
- Se usuário conecta na instância A
- E evento é gerado na instância B
- Usuário NÃO recebe notificação

**Solução proposta**: Redis como backplane para sincronização:

```php
// API Service publica para TODOS os workers
$redis->publish('ws:events', json_encode([
    'user_id' => $userId,
    'event' => $event
]));

// CADA worker verifica se tem a conexão
$redis->subscribe(['ws:events'], function($message) {
    $data = json_decode($message);
    if (isset($this->userConnections[$data['user_id']])) {
        $this->notifyUser($data['user_id'], $data['event']);
    }
});
```

#### Limitação 2: Sem Persistência de Conexões

**Problema**: Se WebSocket Worker reinicia, todas as conexões são perdidas.

**Impacto**: Clientes precisam detectar desconexão e reconectar manualmente.

**Solução proposta**: Auto-reconnect no cliente com exponential backoff:

```javascript
class WebSocketClient {
    constructor(url) {
        this.url = url;
        this.retryDelay = 1000;
        this.maxRetryDelay = 30000;
        this.connect();
    }

    connect() {
        this.ws = new WebSocket(this.url);
        
        this.ws.onclose = () => {
            console.log(`Reconectando em ${this.retryDelay}ms...`);
            setTimeout(() => this.connect(), this.retryDelay);
            this.retryDelay = Math.min(this.retryDelay * 2, this.maxRetryDelay);
        };

        this.ws.onopen = () => {
            this.retryDelay = 1000; // Reset delay on success
            this.authenticate();
        };
    }
}
```

#### Limitação 3: Sem Rate Limiting

**Problema**: Cliente malicioso pode enviar milhares de mensagens.

**Impacto**: DoS no WebSocket Worker.

**Solução proposta**: Rate limiting por conexão:

```php
private array $messageCount = []; // resourceId => count
private array $messageWindow = []; // resourceId => timestamp

public function onMessage(ConnectionInterface $from, $msg): void
{
    $resourceId = $from->resourceId;
    $now = time();
    
    // Reset contador a cada minuto
    if (($this->messageWindow[$resourceId] ?? 0) < $now - 60) {
        $this->messageCount[$resourceId] = 0;
        $this->messageWindow[$resourceId] = $now;
    }
    
    $this->messageCount[$resourceId]++;
    
    if ($this->messageCount[$resourceId] > 100) { // 100 msg/min
        $from->send(json_encode([
            'type' => 'error',
            'message' => 'Rate limit exceeded'
        ]));
        return;
    }
    
    // Processar mensagem...
}
```

#### Limitação 4: Divergência de Porta

**Problema**: Requisito especifica porta 8082, implementação usa 8081.

**Impacto**: Documentação e código divergentes causam confusão.

**Solução**: Corrigir `WEBSOCKET_PORT` para 8082 ou atualizar requisito.

### 6.3 Pontos Fortes

1. **JWT consistente**: Mesma autenticação HTTP e WebSocket
2. **Redis Pub/Sub**: Desacoplamento entre API e WebSocket Worker
3. **ReactPHP**: Event loop eficiente para I/O bound workloads
4. **Múltiplas conexões por usuário**: Suporta mesmo usuário em vários dispositivos

## 9. Cliente JavaScript de Referência

```javascript
class Chat4AllWebSocket {
    constructor(url, token) {
        this.url = url;
        this.token = token;
        this.handlers = {};
        this.connect();
    }

    connect() {
        this.ws = new WebSocket(this.url);
        
        this.ws.onopen = () => this.authenticate();
        this.ws.onmessage = (event) => this.handleMessage(event);
        this.ws.onclose = () => this.reconnect();
        this.ws.onerror = (error) => console.error('WebSocket error:', error);
    }

    authenticate() {
        this.send({ type: 'auth', token: this.token });
    }

    send(data) {
        this.ws.send(JSON.stringify(data));
    }

    handleMessage(event) {
        const data = JSON.parse(event.data);
        
        if (this.handlers[data.type]) {
            this.handlers[data.type](data);
        }
    }

    on(type, handler) {
        this.handlers[type] = handler;
    }

    reconnect() {
        setTimeout(() => this.connect(), 3000);
    }

    // Keep-alive
    startHeartbeat() {
        setInterval(() => {
            if (this.ws.readyState === WebSocket.OPEN) {
                this.send({ type: 'ping' });
            }
        }, 30000);
    }
}

// Uso
const ws = new Chat4AllWebSocket('ws://localhost:8082', 'jwt_token_here');

ws.on('auth_success', (data) => {
    console.log('Autenticado como:', data.user_id);
    ws.startHeartbeat();
});

ws.on('status_update', (data) => {
    console.log(`Mensagem ${data.message_id} agora é ${data.status}`);
    updateMessageUI(data.message_id, data.status);
});

ws.on('new_message', (data) => {
    console.log('Nova mensagem:', data);
    addMessageToConversation(data);
});
```
